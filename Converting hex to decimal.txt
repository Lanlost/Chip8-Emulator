For a four-digit number ABCD:
Digit	Formula
A (thousands)	(ABCD / 1000)
B (hundreds)	(ABCD / 100) % 10
C (tens)	(ABCD / 10) % 10
D (ones)	(ABCD / 1) % 10
Assuming integer division.
The trick is dividing first to move the digit you want into the ones position, then using % 10 to discard everything to its left.

Also my idea to pop off a digit from the right works:

So with 1234:
- 1234 % 10 = 4, then 1234 / 10 = 123
- 123 % 10 = 3, then 123 / 10 = 12
- 12 % 10 = 2, then 12 / 10 = 1
- 1 % 10 = 1


number = 1234;

digitCount = 1;

while (temp >= 10) {
    temp = temp / 10;
    digitCount++;
}

digits = new int[digitCount];

for (index = digitCount - 1; index >= 0; index--) {
    digits[index] = number % 10;
    number = number / 10;
}
